Kiosk Desktop Viewer

Pilih Setting → Setting URL & Profil... di Window Menu atau klik tombol di bawah untuk memasukkan URL Webview.

Setting Kiosk Webview

Profil ini aktif dari Shortcut Desktop. Nama profil terkunci sesuai shortcut.
Terkunci
Nama profil tidak dapat diubah karena mengikuti shortcut desktop.

Aplikasi akan langsung tampil di layar monitor yang dipilih saat dibuka.

Panduan Singkat Penggunaan
  • Mode Default: Menyimpan 1 URL utama untuk aplikasi secara umum.
  • Mode Multi Profile: Digunakan untuk menyimpan beberapa profil berbeda dan membuat file .lnk (Shortcut Desktop) khusus per profil.
  • Layar Tertentu: Aktifkan toggle jika komputer memiliki lebih dari 1 monitor dan ingin aplikasi selalu terbuka di layar yang dipilih.
  • Shortcut Keyboard: Tekan Ctrl+S untuk buka Setting, Esc untuk keluar Fullscreen.
